# data — машинно-читаемые артефакты разбора

| файл | что внутри |
|---|---|
| `parsed.json` | разобранная структура «Путь к вскрытию» 3.0 и 4.0 (уровни → пункты → тело/ссылки) |
| `index_4.0.csv` / `index_4.0.json` | плоский индекс 492 пунктов: уровень, номер, заголовок, тело, ссылки, флаги |
| `stats.json` | сводная статистика архива |
| `diff_3.0_4.0.md` | поимённый дифф версий |
| `verdicts.json` | 66 вручную проверенных пунктов: категория, вердикт, источники |
| `puzzles.json` | «пункты-калеки» (испорченный перевод) и их оригиналы |
| `url_problems.json` | 89 ссылок, которые не открываются как есть, с файлом и строкой |

Всё воспроизводится скриптами из `tools/` (см. §13 отчёта в `analysis/`).
